# Inline functions

For simple cases having to create an `entry.js` or similar each time is redudant. Instead this should be possible:

```javascript
await createTransport({
  entry: async (ctx) => {
    // worker
  }
})
```

# Logging

Signals were a nice idea but taking control over STDOUT/STDERR was a mistake in hindsight as it introduces complexity for no real benefit.
